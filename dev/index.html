Introduction

AdaptiveVisualization adaptively samples functions of two variables and displays their values on a triangulated mesh. For functions of more variables, it can visualize a two-dimensional slice. Its HomotopyContinuation integration explores how solution counts change across parameter spaces.

Start with Getting started for installation and examples. The following pages describe visualization, refinement, and polynomial-system integration, with the relevant function and type docstrings alongside each topic.
